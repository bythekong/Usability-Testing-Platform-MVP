# Landing hero video brief

Expected hero background asset:

`hero_background_001.webm`

Public URL used by the landing page:

`/home_video/hero_background_001.webm`

Recommended export:
- 16:9 or wider
- 1920×1080 working size
- WebM (VP9 or AV1)
- muted/no audio track required
- 8–15 second seamless loop
- keep the visual center relatively calm because headline and CTAs sit in the middle
- avoid readable third-party brand names
- prefer real usability-testing footage: laptop interaction, cursor movement, task overlay, observer notes, hands/face details, subtle product UI
- avoid rapid cuts; the hero uses scroll-linked scale/parallax so slower footage reads better

The layout includes a dark readability overlay, so the source video can retain natural highlights and color.
